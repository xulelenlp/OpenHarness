# 三智能体编排（multi-agent-orchestration）

## 三个智能体的定位

| 智能体 | 最擅长 | 不用于 |
| --- | --- | --- |
| `smart-data-query` | 数值/明细/多维度查询、图表数据 | 归因、政策、报告写作 |
| `power-grid-analysis` | 趋势、同比环比、归因假设、影响链、分析报告 | 单值取数、政策原文 |
| `knowledge-qa` | 政策/文件/背景/术语/制度依据 | 实时业务数据、指标计算 |

## 原则

1. **一个任务可以调 0–3 个**，不要固定只调一个。
2. **数字以 `db_query` 为准**；智能体数字只作对照/补充。
3. **共享同一份事实**：把已核验数据放进 `shared_context`，避免每个智能体各查一套。
4. **并行用于独立任务**：取数复核 + 归因 + 政策解读可并行；有依赖时用顺序。
5. **调用不是结束**：必须核验、去重、消矛盾、重新组织；不要整段粘贴。

## 推荐用法

### 复杂业务分析（一次批量）

```text
consult_agents(
  mode="parallel",
  shared_context="""已核验数据（2026-09，福建，售电量）：
- 全省 64.9459 亿千瓦时，同比 -6.31%，环比 -9.17%
- 第一产业 1.1044，同比 -13.85%；第二产业 36.7980，+0.20%；第三产业 13.8416，-5.23%
- 九地市同比：福州 -9.40、莆田 -20.22、泉州 -7.48……
口径：月度，stat_date=2026-09-30，来源 zhss_result_data_qs/ds/khydl_ssx。""",
  calls=[
    {"agent":"smart-data-query","purpose":"取数复核","message":"请复核福建2026年9月分产业、分地市售电量及同比；只返回数值表，不要归因。"},
    {"agent":"power-grid-analysis","purpose":"归因假设","message":"基于上面的已核验数据，分析福建2026年9月售电量同比下降的主要成因，按产业/地市/政策三条线给出假设和需要的数据证据；不要重新取数，不要编造。"},
    {"agent":"knowledge-qa","purpose":"政策解读","message":"解读2025年10月福建新能源上网电价市场化改革对2026年售电量/电价的影响路径，给出来源和时间。"}
  ]
)
```

### 单值查询

直接用 `db_query`；只有口径复杂/库里查不到时，再调 `smart-data-query` 对照。

### 政策/背景

`knowledge-qa` + `db_query(news)` + `web_search`；要求给出来源和时间。

## 综合检查表

- [ ] 每个数字有指标/机构/周期/日期/单位/来源。
- [ ] 智能体数字与库冲突 → 以库为准，记录差异。
- [ ] 统一时间/口径/单位，剔除重复和矛盾。
- [ ] 区分事实、推断、建议；标注置信度。
- [ ] 失败项已说明，没有用记忆数据补齐。
- [ ] 最终回答是重新组织的，不是智能体原文拼接。

## 失败处理

- 502/超时/会话创建失败：`consult_agents` 已自动重试 1 次；仍失败换另一个智能体或 `db_query`。
- 外部输出超长：完整原文在 `outputs/agents/`，模型只看预览。
- 不要向用户展示 agent id / 路由推理 / 工具名。
